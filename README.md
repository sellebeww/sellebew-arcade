# Sellebeww Arcade

Jawab empat pertanyaan singkat, lalu mainkan game pixel-art buatanmu sendiri di mesin arcade 3D.

## Jalankan

Butuh Node.js 20+.

```bash
npm install
cp .env.example .env.local   # isi GEMINI_API_KEY
npm run dev
```

Build produksi: `npm run build` lalu `npm start`.
